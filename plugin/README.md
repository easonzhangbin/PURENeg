# Film Dust Local 0.1.1 · PhotoCraft 标准插件

解压插件包，在「滤镜 → 插件 → 安装插件…」选择 `film-dust-local.wasm`。

## 预览与确认

1. 用 `⌘J` 复制照片图层，选中上方副本。从「滤镜 → 插件 → Film Dust Local」打开参数窗口。
2. 白色灰尘将 `polarity` 设为 `bright`，黑色灰尘设为 `dark`。`maxSize` 控制最大灰点直径（2–16 像素）。`sensitivity` 越大，检测越激进，可以从 1 开始。
3. 勾选对话框的「预览」，将 `preview` 切为 `mark`。画布上的橙色点是检测位置，灰度图中显示为亮点。开关「预览」可与原图对照，点「取消」可丢弃预览。
4. 大图开启「低分辨率预览」时，PhotoCraft 会先缩小图像再检测，整图预览可能漏掉细小灰点。要按原像素核对，先把画布放到 100%，定位要看的区域。在「首选项 → 性能」关闭「低分辨率预览」，可用矩形选框圈住小块区域，再打开滤镜查看局部标记。100% 调整的是画布显示比例，检测分辨率由首选项控制。
5. 要处理整张照片，先取消局部预览和选区，再打开滤镜。将 `preview` 设为 `repair`，然后点击「确定」应用全分辨率修复。请把 `mark` 留在预览阶段。

## 自动后手工修正

给处理后的副本图层添加全白蒙版。

- **误擦了拉链、纽扣或真实纹理**。选蒙版缩略图，用黑色画笔涂抹对应位置，显示下方原图。白色可重新显示自动修复结果。
- **仍有灰尘漏修**。选上方副本的图像缩略图，用污点修复画笔（J 工具组）点掉灰尘。
- 隐藏或删除上方副本即可查看原图。

插件专门处理局部小灰点。长毛发、柔斑或逐点审核可使用项目中的 Film Dust Review 应用。

支持 8/16 位 RGB 和灰度，在不透明区域处理，并保留 alpha 通道。

在本地运行。使用 MIT 许可，设计参考 Magnus Holmes 的 [film-dust](https://github.com/magholmes/film-dust)。
